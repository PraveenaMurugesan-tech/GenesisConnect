# GenesisConnect — Backend API & Database Service

Official backend application for **Genesis Power Equipments Pvt. Ltd. (GenesisConnect)**.  
Built with **FastAPI**, **SQLAlchemy 2.0**, **PostgreSQL**, **Alembic**, and **Pydantic v2**.

---

## 1. Architecture & Tech Stack

```
Frontend (React 18 + Vite)
         ↓
  Product Service Layer
         ↓
    Axios HTTP API
         ↓
  FastAPI (REST Endpoints)
         ↓
  Product Service & Repository
         ↓
  SQLAlchemy 2.0 ORM
         ↓
     PostgreSQL
```

* **Framework**: FastAPI (ASGI with Uvicorn)
* **ORM & Database**: SQLAlchemy 2.0 + PostgreSQL (`psycopg` / `psycopg2`)
* **Migrations**: Alembic
* **Data Validation & Schemas**: Pydantic v2 + Pydantic Settings
* **Testing**: Pytest + FastAPI TestClient (with isolated test runner)

## 3. Local Setup Instructions

### Step 1: Create and Activate Virtual Environment

```bash
# In the backend directory
python -m venv .venv

# Windows (PowerShell):
.\.venv\Scripts\Activate.ps1

# Linux / macOS:
source .venv/bin/activate
```

### Step 2: Install Dependencies

```bash
pip install -r requirements.txt
```

### Step 3: Configure Environment Variables

Copy the example environment file:

```bash
cp .env.example .env
```

Update your `.env` values as required:

```env
PROJECT_NAME="GenesisConnect API"
APP_ENV=development
API_V1_PREFIX=/api/v1
BACKEND_PORT=8000
BACKEND_HOST=0.0.0.0
FRONTEND_URL=http://localhost:5173
CORS_ORIGINS=["http://localhost:5173","http://localhost:3000","http://127.0.0.1:5173","http://127.0.0.1:3000"]

# PostgreSQL connection string
DATABASE_URL=postgresql://postgres:postgres@localhost:5432/genesisconnect
```

## 4. PostgreSQL Database & Migrations

### Apply Migrations

Ensure your PostgreSQL service is running and the database exists (`CREATE DATABASE genesisconnect;`), then run:

```bash
alembic upgrade head
```

To preview SQL generated by migrations offline:

```bash
alembic upgrade head --sql
```

## 8. API Contract & Endpoints

### Health Check

* `GET /api/health` — Lightweight health probe
  ```json
  { "status": "ok" }
  ```
* `GET /api/v1/health` — API v1 health with system metadata
  ```json
  {
    "status": "ok",
    "project": "GenesisConnect API",
    "environment": "development",
    "version": "1.0.0"
  }
  ```

### Products Catalog

* `GET /api/v1/products` — List all active products
  * **Query Parameters**:
    * `category` (optional, string): Filter by category (`UPS`, `Voltage Stabilizers`, `Power Conditioning`, `Medical Power Solutions`, `Other`)
    * `search` (optional, string): Keyword search across name, description, tagline, slug
    * `skip` (optional, int, default: 0): Pagination offset
    * `limit` (optional, int, default: 50, max: 100): Result page limit

* **Examples**:
  * All products: `GET /api/v1/products`
  * Filter by category: `GET /api/v1/products?category=UPS`
  * Full-text search: `GET /api/v1/products?search=industrial`
  * Combined filter: `GET /api/v1/products?category=UPS&search=industrial`

* `GET /api/v1/products/{slug}` — Retrieve single product by slug
  * Example: `GET /api/v1/products/industrial-ups`
  * Returns: 200 with full technical specifications, features, images, and marketing metadata.
  * If not found: Returns 404 Not Found:
    ```json
    { "detail": "Product with slug 'xyz' not found", "status_code": 404 }
    ```
